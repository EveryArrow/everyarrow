# Security Policy

## Supported Versions

Public release support starts with the first tagged public release. Until
then, security fixes are handled on active development branches only.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability.

Send a private report to `security@everyarrow.io` with:

- affected commit or version
- affected connector, behavior, or workflow
- reproduction steps that do not include real secrets
- impact summary
- any safe proof-of-concept data

EveryArrow will acknowledge receipt, triage severity, and coordinate a fix
or disclosure path before public details are published.

## Sensitive Data

Do not include real credentials, customer data, private keys, tokens, or
production endpoint details in reports, examples, logs, or test artifacts.
