# DEAL language artifact

`deal-language-1.1.json` is generated from the Java `DealLanguage` and
`FunctionRegistry` contracts. Do not edit it independently.

`DealLanguageArtifactTest` verifies the checked-in artifact and writes the
current generated form to `target/generated-deal/` for inspection or syncing
to non-Java consumers.

Public language-artifact documentation belongs beside this generated contract.
